# Android Gradle Wrapper — One-Time Setup

This directory (`app/android/`) contains a `gradle/wrapper/gradle-wrapper.properties`
that pins **Gradle 8.7**, but it does **not** ship the wrapper scripts
(`gradlew` / `gradlew.bat`) or the binary bootstrap jar
(`gradle/wrapper/gradle-wrapper.jar`).

Those files are either auto-generated by your IDE or by a single CLI command, and
the jar is a binary that does not belong in source control.

---

## Why they are not committed

| File | Reason not committed |
|---|---|
| `gradlew` / `gradlew.bat` | Generated boilerplate; IDEs regenerate on import |
| `gradle-wrapper.jar` | Binary artifact (~60 KB); tracked in version control adds noise and diff noise with every Gradle bump |

---

## One-time generation (required before first build)

> [!IMPORTANT]
> You only need to do this once per developer machine, or whenever you upgrade
> the Gradle version in `gradle-wrapper.properties`.

### Option A — Android Studio (recommended)

1. Open **Android Studio**.
2. Choose **File → Open** and select the `app/android/` folder.
3. Android Studio detects the missing wrapper and regenerates it automatically.
4. You are done.

### Option B — CLI (requires any local Gradle install, version ≥ 7)

```bash
cd app/android
gradle wrapper --gradle-version 8.7 --distribution-type bin
```

This generates:
- `gradlew` (Unix shell script — mark executable: `chmod +x gradlew`)
- `gradlew.bat` (Windows batch script)
- `gradle/wrapper/gradle-wrapper.jar`

After generation, all subsequent builds use `./gradlew` (the version-pinned
wrapper) instead of the system Gradle.

### Option C — Copy from another Android project

If you already have a recent Android project on this machine you can copy:

```
<other-project>/android/gradlew          → app/android/gradlew
<other-project>/android/gradlew.bat      → app/android/gradlew.bat
<other-project>/android/gradle/wrapper/gradle-wrapper.jar
                                         → app/android/gradle/wrapper/gradle-wrapper.jar
```

Then edit `gradle/wrapper/gradle-wrapper.properties` to confirm the version
matches what this project requires (currently 8.7).

---

## After setup

Once the wrapper files exist:

```bash
# Build the Android app (from repo root or app/)
cd app
flutter build apk        # invokes Gradle via flutter's own wrapper layer

# Or invoke Gradle directly (e.g. to build the :widget module in isolation)
cd app/android
./gradlew :widget:assembleDebug
```

Remember to also copy `local.properties.example` → `local.properties` and fill
in your local Android SDK path before the first build.
